# Learn & Earn - Rewiring Education with Reward-Based Logic

A modern web platform that combines education with financial incentives, where curiosity is currency and knowledge pays off, literally.

## 🌟 Features

- **Mobile Number Login**: Secure authentication with OTP verification
- **User Management**: Track user logins, earnings, and course completions
- **Excel Export**: Export user data and summaries to Excel format
- **Course Catalog**: Browse and learn from various AI tools and courses
- **Responsive Design**: Beautiful, modern UI that works on all devices

## 📋 Available Courses

1. **Whispr Flow** - Speech to text conversion in real-time
2. **Gemini** - Google's AI assistant
3. **Emily** - AI tool for ML and microservice projects
4. **Fireflies** - Meeting transcription and summarization
5. **ChatGPT** - OpenAI's conversational assistant
6. **Claude** - Anthropic's AI model
7. **Phot AI** - AI-powered photo editing and generation

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- No server required - runs entirely in the browser

### Installation

1. Clone the repository:
```bash
git clone https://github.com/SahSanjeev/Learn-earn.git
cd Learn-earn
```

2. Open `index.html` in your web browser:
```bash
# On Windows
start index.html

# On macOS
open index.html

# On Linux
xdg-open index.html
```

Or simply double-click the `index.html` file.

## 🔐 Login System

The platform includes a complete login system:

1. **Mobile Number Login**: Enter your mobile number
2. **OTP Verification**: Verify with a 6-digit OTP code
3. **User Tracking**: All logins are tracked with timestamps
4. **Data Export**: Export all user data to Excel

### How to Login

1. Click the "Login" button in the navigation bar
2. Enter your mobile number (10-15 digits)
3. Optionally enter your name
4. Click "Send OTP"
5. Enter the 6-digit OTP displayed on screen
6. Click "Verify & Login"

### Exporting Data

1. After logging in, click "Export Data" button
2. An Excel file will be downloaded with:
   - User data sheet (all user information)
   - Summary sheet (aggregated statistics)
